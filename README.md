# Team-Based Learning Certificate Portfolio

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of the `tbl-certificate-portfolio` folder to the repository root.
3. Commit the files to the default branch.
4. Open **Settings**, then **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose the default branch and root folder, then save.
7. Open the published URL and test the navigation, accordion transcriptions, image enlargement, embedded documents, video, and downloads.

## Local preview
Run `python3 -m http.server 8000` in this folder and open `http://localhost:8000`.

## Primary files
- `index.html`: homepage
- `assessment-map.html`: assessor map, linked from the homepage
- `flexible-criteria.html`: complete Flexible Criteria document and artifacts
- `downloads.html`: complete portfolio PDF and source documents
- `integrity.html`: authorship and academic-integrity statement, linked only from the homepage
